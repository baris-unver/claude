geoloc-tr — where was this photo taken?

Finds where a photo was taken inside Ankara. Two models: street-level photos, trained on 144,072 Mapillary images, and overhead photos, trained on Esri imagery tiles. DINOv2 ViT-S/14 with proxy classification over S2 cells, a city-scale adaptation of Lindenberger et al., NeurIPS 2025.

Samples

Chosen across the whole error distribution, not only successes; the label is the measured error. ● streets the model saw / current imagery · ● blocks with no training data / imagery dates the model never saw (Wayback 2023, 2017).

Uploads

Street photos run the full method. Aerial photos of ~50 m to ~2 km across run the coarse-to-fine pyramid: the model estimates the ground extent itself, or give metres per pixel if you know it. Photos are processed on this machine and not stored.
